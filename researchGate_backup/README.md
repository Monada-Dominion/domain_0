## How to update
1. Log into your ResearchGate profile and save the page as an HTML file named `rg_profile.html` in this folder.
2. Run the update script to refresh this table:
   ```bash
   python3 researchGate_backup/check_backups.py
   ```
3. Commit and push the changes.
